## How I work

- **Verify, don't trust.** My agent does not take the model's word for its sources; the loop enforces it in code.
- **Don't fabricate.** When data is missing I leave it missing or flag the imputed value, never quietly invent it.
- **Ship it.** If it can be deployed, it gets a live link.
